💡 Jak to wygląda w kodzie?

To uproszczony pseudokod — bez Pitagorasa i bez trudnych słów. Cała „mądrość” Aikiego to lista przykładów!

// Pamiętnik — tu trzymamy to, czego się nauczyliśmy
let pamiętnik = [];

// KROK 1–3: Ty uczysz Aikiego
function naucz(zdjęcie, etykieta) {
  pamiętnik.push({ zdjęcie, etykieta });
}

// KROK 4: Aiki zgaduje nowe zdjęcie
function zgadnij(noweZdjęcie) {
  let koty = pamiętnik.filter(p => p.etykieta === "kot").length;
  let psy  = pamiętnik.filter(p => p.etykieta === "pies").length;
  if (koty > psy) return "To kot!";
  if (psy > koty) return "To pies!";
  return "Nie wiem — pokaż mi więcej!";
}

🔑 Co właśnie zrobiłeś?

  1. 1Dane treningowe = zdjęcia z etykietami, które sam dodałeś
  2. 2Etykieta = odpowiedź „kot” lub „pies”, którą podajesz AI
  3. 3Predykcja = zgadywanie na podstawie tego, czego AI się nauczyła
  4. 4Im więcej przykładów, tym lepiej — dokładnie jak Ty uczysz się nowych słów!

Czym jest k-NN?

👆 kliknij
Czym jest k-NN?

k-NN (k-Nearest Neighbors) to prosty algorytm: nowy punkt sprawdza, którzy są jego k najbliższych sąsiadów i głosuje tak jak oni!

🧮

Jak to działa?

👆 kliknij
Jak to działa?

Mierzymy odległość (Pitagoras!) od nowego punktu do wszystkich znanych. Wybieramy k najbliższych i sprawdzamy, do jakiej grupy większość należy.

💻

Kod w 30 liniach!

👆 kliknij
Kod w 30 liniach!

Cały algorytm k-NN mieści się w kilkudziesięciu liniach JavaScript. Zobaczysz to na żywo poniżej — możesz skopiować kod i badać go sam!

🎮 Interaktywna demo: Rysuj punkty i ucz AI!

Klikaj na planszę, by dodać punkty dwóch kolorów. AI uczy się na Twoich przykładach i od razu przewiduje kolor nowych punktów!

Czerwona klasa
Niebieska klasa
Przewidywanie AI (najedź kursorem)
Czerwone: 0 Niebieskie: 0 k = 3

Najedź kursorem na planszę (po dodaniu punktów), żeby zobaczyć przewidywanie AI.

🧒 Co tu się dzieje?

To jak gra w „zgadywanie na podstawie sąsiadów”. AI nie zna magicznych sztuczek — po prostu patrzy, jakie punkty są blisko!

1Wybierz kolor (czerwony lub niebieski) i kliknij planszę — to Twoje przykłady, z których AI się uczy.
2Kolorowe tło to mapa przewidywań — różowe i niebieskie strefy pokazują, co AI „myśli” o każdym miejscu na planszy.
3Najedź kursorem — żółty marker mówi: „gdyby tu wpadł nowy punkt, wybrałbym ten kolor!”
4AI szuka k najbliższych punktów (sąsiadów) i głosuje — jak na lekcji wykopów: większość wygrywa!
5Suwakiem k zmieniasz liczbę sąsiadów: małe k = granica bardziej poszarpana, duże k = bardziej gładka i spokojna.

💡 Jak to działa w kodzie?

Oto kompletny, działający kod algorytmu k-NN. Skopiuj go do pliku index.html i otwórz w przeglądarce!

<!DOCTYPE html>
<html lang="pl">
<head>
  <meta charset="UTF-8">
  <title>Mój pierwszy AI</title>
  <style>
    canvas { border: 2px solid #7C3AED; border-radius: 12px; background: #1A1035; }
  </style>
</head>
<body style="font-family:sans-serif;text-align:center;padding:2rem;background:#0F0A1E;color:#F1F0FF">
  <h1>🤖 k-NN Demo</h1>
  <canvas id="c" width="500" height="350"></canvas>
  <br><button onclick="clearPoints()">Wyczyść</button>
  <script>
// Dane treningowe: [{x, y, color}, ...]
const points = [];
let currentColor = 'red';
const k = 3;

// Odległość euklidesowa (twierdzenie Pitagorasa!)
function dist(a, b) {
  return Math.hypot(a.x - b.x, a.y - b.y);
}

// Główna funkcja AI: przewiduje kolor punktu
function predict(x, y) {
  // 1. Oblicz odległości do WSZYSTKICH punktów treningowych
  const distances = points.map(p => ({ color: p.color, d: dist(p, {x, y}) }));

  // 2. Posortuj od najbliższego
  distances.sort((a, b) => a.d - b.d);

  // 3. Weź k najbliższych sąsiadów
  const neighbors = distances.slice(0, k);

  // 4. Głosowanie większościowe
  const redVotes = neighbors.filter(n => n.color === 'red').length;
  return redVotes > k/2 ? 'red' : 'blue';
}

// Rysowanie: punkty treningowe + siatka przewidywań
function draw() {
  const ctx = c.getContext('2d');
  ctx.clearRect(0, 0, c.width, c.height);

  // Siatka: pokaż co AI "myśli" o każdym punkcie
  for (let x = 0; x < c.width; x += 20)
    for (let y = 0; y < c.height; y += 20) {
      const pred = predict(x, y);
      ctx.fillStyle = pred === 'red' ? 'rgba(236,72,153,0.1)' : 'rgba(6,182,212,0.1)';
      ctx.fillRect(x, y, 20, 20);
    }

  // Punkty treningowe
  points.forEach(p => {
    ctx.beginPath();
    ctx.arc(p.x, p.y, 8, 0, Math.PI*2);
    ctx.fillStyle = p.color === 'red' ? '#EC4899' : '#06B6D4';
    ctx.fill();
    ctx.strokeStyle = '#fff'; ctx.lineWidth = 2; ctx.stroke();
  });
}

// Kliknięcie = dodaj punkt treningowy
c.onclick = e => {
  const rect = c.getBoundingClientRect();
  points.push({ x: e.clientX - rect.left, y: e.clientY - rect.top, color: currentColor });
  draw();
};

// Zmiana koloru
function setColor(c) { currentColor = c; }
function clearPoints() { points.length = 0; draw(); }

draw(); // Pierwsze rysowanie
  </script>
</body>
</html>

Skopiowano! Wklej do pliku .html i otwórz w przeglądarce.

🔑 Kluczowe pojęcia, które się tu uczysz

  1. 1Dane treningowe = punkty, które Ty "nauczasz" AI (klikasz je sam!)
  2. 2Cecha (feature) = tutaj po prostu współrzędne X i Y punktu
  3. 3Odległość euklidesowa = pierwiastek z (Δx² + Δy²) — twierdzenie Pitagorasa!
  4. 4Parametr k = ile sąsiadów bierze pod uwagę (małe k = niestabilne, duże = rozmyte)
  5. 5Głosowanie większościowe = klasa, która ma więcej głosów wśród sąsiadów, wygrywa
  6. 6Granica decyzyjna = linia (tutaj: kolorowe tło), gdzie AI zmienia zdanie

🧪 Eksperymenty do wypróbowania

  • Ustal k=1 i zobacz, jak granica staje się "zackata" (overfitting)
  • Ustal k=15 i zobacz, jak granica się wygładza (underfitting)
  • Dodaj tylko punkty czerwone w jednym rogu — co AI przewiduje w środku?
  • Stwórz "wyspę" niebieskich punktów w morzu czerwonych — czy AI to rozpozna?
  • Dodaj po 20 punktów każdego koloru, potem usuń kilka — jak zmienia się granica?

Chcesz więcej? Spróbuj dodać trzecią klasę (zieloną), albo zmień odległość na Manhattan (|Δx| + |Δy|)!
